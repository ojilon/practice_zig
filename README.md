# practice_zig

A long-term personal dojo for becoming dangerous with **Zig** as a systems programming language.

**Goal:** Gain deep, practical fluency in Zig by building real tools, libraries, parsers, and low-level systems. The journey emphasizes:

- Mastery of the language, allocators, and the **build system**
- Writing useful libraries and internal tools
- Parsing real formats (documents, media containers, structured data)
- Reading and implementing research papers and classic systems ideas
- TUI applications
- Progressive path toward a small language / compiler (advanced)
- Critical, functional low-level applications and tools that you would actually run

This is deliberately parallel in spirit to `practice_go` and `practice_odin`, but oriented around Zig’s strengths: explicit control, comptime, cross-compilation, build.zig, and systems work.

The journey is designed for **12–18 months** of steady work. Experience and shippable artifacts matter more than perfection.
