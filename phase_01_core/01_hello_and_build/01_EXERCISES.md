# Exercises — Hello and Build

## Must implement

1. A `build.zig` that defines at least one executable.
2. A `main` that prints a visible message.
3. At least one `test` block that passes.

## Stretch
- Add a build option (e.g. a simple boolean flag) and read it.
- Add a second step (e.g. a second test executable or a library target).

## Notes
No complex memory work yet. Focus on the edit → build → run/test loop.
